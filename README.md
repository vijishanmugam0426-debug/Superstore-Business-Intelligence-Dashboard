# 📊 Superstore Business Intelligence Dashboard

## 🚀 Project Overview

This project is an end-to-end Business Intelligence solution developed using **SQL** and **Power BI** to transform raw retail sales data into actionable business insights.

The dashboard enables stakeholders to monitor key business metrics, identify sales trends, analyze customer behavior, evaluate product performance, and optimize order management through interactive visualizations.

---

## 🛠️ Tools & Technologies

| Tool      | Purpose                  |
| --------- | ------------------------ |
| MySQL     | Data Storage & Querying  |
| SQL       | Data Cleaning & Analysis |
| Power BI  | Dashboard Development    |
| Excel/CSV | Dataset Source           |

---

## 📈 Key Performance Indicators (KPIs)

* 💰 Total Sales
* 📊 Total Profit
* 📦 Total Orders
* 👥 Total Customers
* 💳 Average Order Value

## 📋 Dashboard Pages

### 1️⃣ Executive Sales Dashboard

Provides a high-level overview of business performance.

**Key Insights:**

* Monthly Sales Trend
* Category Performance
* Top Products Analysis
* Regional Performance Overview

---

### 2️⃣ Customer Analytics Dashboard

Analyzes customer behavior and purchasing patterns.

**Key Insights:**

* Customer Distribution by Region
* State-wise Customer Analysis
* Customer Segment Performance
* Top Customers by Sales
* Customer Activity Trends

---

### 3️⃣ Product Analytics Dashboard

Evaluates product-level performance and profitability.

**Key Insights:**

* Category Sales Analysis
* Sub-Category Performance
* Product Revenue & Profit Analysis
* Product Demand Trends
* Top Performing Products

---

### 4️⃣ Order Analytics Dashboard

Provides operational insights into order performance.

**Key Insights:**

* Order Volume Analysis
* Regional Order Distribution
* Most Ordered Products
* High-Value Orders Analysis
* Monthly Order Trends

---

## 🎯 Business Insights Generated

✔ Technology category generated the highest revenue.

✔ Consumer segment contributed the largest share of total sales.

✔ Several high-value orders resulted in negative profitability due to discounts.

✔ Customer purchasing behavior varied significantly across regions.

✔ Product demand patterns showed clear seasonal fluctuations.
